Linux常用命令速查笔记

一、基础帮助与系统控制
命令 说明
命令 --help 查看指定命令的帮助信息
man 命令 查看系统手册的详细帮助信息
clear 清屏操作
sync 将内存中的数据强制写入磁盘（防止数据丢失）
poweroff 立即关机
二、目录导航
命令 说明
ls 查看当前目录下的文件和文件夹
ls -a 显示所有文件，包括隐藏文件（以.开头的文件）
ls -l 以列表形式显示，包含文件权限、所有者、修改时间等详细信息
cd / 切换到系统根目录
cd ~ 切换到当前用户的home目录
cd ../ 返回上一级目录
cd ../../../ 连续返回三级目录（可根据需要增减../数量）
三、文件与目录操作
命令 说明
touch 文件名 创建空文件（原笔记torch为笔误）
mkdir 文件夹名 创建新文件夹
cp 源文件 目标文件 复制文件，例：cp a.c b.c 复制a.c为b.c
mv 源文件 目标路径/ 移动文件到指定目录，例：mv a.c test/
mv 旧文件名 新文件名 重命名文件，例：mv a.c b.c
rm 文件名 删除文件
rm -r 文件夹名 递归删除文件夹及其所有内容
rm -f 文件名 强制删除文件，无需确认
rm -rf 文件夹名 ⚠️ 强制递归删除文件夹（危险操作，谨慎使用）
gedit 文件名 用图形化文本编辑器打开文件（类似Windows记事本）
file 文件名 查看文件的类型信息
四、权限与用户管理
命令 说明
sudo 命令 以root管理员权限执行单条命令
sudo su ⚠️ 切换到root用户（全程拥有最高权限，极度谨慎使用）
sudo su 用户名 从root用户切回指定普通用户，例：sudo su ahshs
五、网络配置
命令 说明
ifconfig 显示当前系统的网络配置信息（IP、网卡等）
sudo ifconfig 网卡名 down 关闭指定网卡，例：sudo ifconfig eth0 down
sudo ifconfig 网卡名 up 开启指定网卡，例：sudo ifconfig eth0 up
六、进程管理
命令 说明
ps 查看当前终端的进程（类似Windows任务管理器）
ps -aux 显示系统中所有进程的详细信息
top 实时查看系统进程运行状态、CPU和内存占用
七、查找命令
命令 说明
find -name 文件名 在当前目录及子目录中查找指定文件，例：find -name a.c
grep -nr "关键词" 路径 递归查找指定路径下包含关键词的文件（原笔记gerp为笔误）
例：grep -nr "ubuntu" / 在整个系统根目录查找"ubuntu"字符串
八、磁盘与文件大小
命令 说明
du 查看文件或目录占用的磁盘空间
du -h 以人类可读的单位（KB/MB/GB）显示大小
du -a 显示目录及其下所有子目录和文件的磁盘占用
du -s 仅显示目录总大小，不显示子目录和文件详情
